UMVC3 Steam Rollback v1.0
made by itsnotbloodborne

Play through normal Steam matchmaking, Player Matches, invitations and lobbies with compatible mod users.

Includes the startup display-list overflow fix, Borderless and V-sync options, and the optional Axis threshold (up): Default / Small setting.

Axis threshold: Brings controller directionality inputs closer to Playstation's defaults. Small halves the upward left-stick travel needed for Up and up-diagonal; Default keeps stock behavior. Restart the game after changing it.

Install: extract the ZIP, open Umvc3RollbackSetup.exe, and click Install / Update.
Previous previews numbered 1.0.x or 3.x require this one-time manual installation because the release numbering has restarted at v1.0. Future updates from this release use the signed automatic updater.

This is the current build previously packaged as v3.0.2, with release naming and descriptions updated. Gameplay is unchanged. Prior releases are archived locally and removed from GitHub. Required third-party notices remain in licenses.
