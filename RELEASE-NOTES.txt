UMVC3 Steam Rollback v3.0.1

Fixes a startup crash on PCs whose graphics drivers report more display modes than the game's 256-entry list can hold. The launcher could report "The game exited before rollback initialization."

The update limits the game's display-mode enumeration to its capacity. On unusually long lists, later display modes may not appear in the game's display options. Combat, inputs, Steam matchmaking, and rollback behavior are unchanged.

Validation: build and regression tests passed for display-list boundary cases and drivers reporting 402 and 1,000 modes. Package checksums verified. Successful launch on the reporting friend's PC still needs confirmation.

Extract the ZIP and run Umvc3RollbackSetup.exe, or accept the launcher update. Install the same version on participating PCs. MinHook and Microsoft Detours notices remain included. No retail game files or private runtime source are included.
